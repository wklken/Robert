## Task

Explain the program tally, agreements, and disagreements for the selected ballots.

## Boundaries

Read only the ballots listed in the synthesis inputs. Do not read unselected runs or other rounds.

## Work

Read every sealed ballot and the program tally from the selected inputs. Explain agreements, disagreements, evidence limitations, and unknowns. Preserve choices, reasons, and counts. Separate your advisory recommendation from the vote outcome and explain any difference.

## Verification

Cover each selected ballot once. Do not claim consensus on a tie, invent missing votes, or treat identical/default models as verified independent model identities.

## Delivery

Write `synthesis.json` with the inputs hash and selected ballot hashes for the controller's final report.
