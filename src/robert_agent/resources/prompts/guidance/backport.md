## backport
The controller assigned one target from an authorized backport request. Use the source_pr_url and target_base_branch in authority.backport. Fetch the source PR's complete ordered commit list and pin its head before applying every commit with cherry-pick -x to the assigned worktree. Resolve conflicts within that patch's intent and run the target branch's supported checks. Record the source head, carried commits and validation in the handoff. An existing target PR resumes on its own branch; do not reapply commits already carried. Each task delivers only its assigned target. Other requested branches have separate tasks. Preserve the source PR and every other target's branch. If the source or target cannot be verified, report the specific missing fact through waiting_for_user.
